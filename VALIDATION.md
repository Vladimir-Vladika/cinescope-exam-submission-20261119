# Результаты проверки — 19 ноября 2026

Среда: Linux, Python 3.12.14; зависимости из requirements.txt.

Команда фактического прогона:

```text
python -m pytest -m public --junitxml=reports/public.xml
10 passed, 22 deselected in 47.17s
```

Все 10 проверок обращались к настоящему стенду, без подмен ответов:
список с пагинацией; 8 некорректных query-параметров; создание без токена (401).

22 административных теста написаны, но **не выполнялись**: нет предоставленной
тестовой учётной записи SUPER_ADMIN. Они исключены явным `-m public`, а не
замаскированы skip/xfail. Полный запуск без настройки авторизации сообщает ошибку.

Схемы и статусы операций сверены со Swagger JSON Movies API и Auth API.
Описание экзамена на странице Coconut School прочитано 19 ноября 2026.
Состав проекта сверён с требованиями; соответствие по пунктам приведено в README.
Незакрытое требование — успешный полный прогон, включая административные тесты.

После сверки выполнены проверка Ruff (правила E, F, I; длина строки 79),
проверка форматирования и `pytest --collect-only`: все проверки успешны,
обнаружены все 32 теста. Изменения Python-файлов касаются оформления и
комментариев; AST до и после форматирования совпадает. Повторный сетевой прогон
для этих изменений не выполнялся; результат 10 passed относится к прогону выше.

Не проверены запуск в Windows и полный прогон с SUPER_ADMIN.
Репозиторий: https://github.com/Vladimir-Vladika/cinescope-exam-submission-20261119
Код для проверки находится в ветке `exam`, целевая ветка Pull Request — `main`.

Перед сдачей: настроить тестовую авторизацию, запустить
`python -m pytest`, устранить обнаруженные расхождения и обновить результаты в PR.
Текущие результаты нельзя трактовать как «все 32 теста прошли».
